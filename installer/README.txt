NORADRENALINE ULTRA — Windows x64 installer

1. Extract the complete ZIP archive to a folder.
2. Double-click Install-NoradrenalineUltra.cmd.
3. Launch NORADRENALINE ULTRA from the Start menu.

The application is installed for the current Windows user and does not require administrator rights. No game files or GPU drivers are included in this package.

To uninstall, use Windows Settings > Apps > Installed apps, or run Uninstall-NoradrenalineUltra.ps1 from the installation folder. Your local game-library list is retained.

The NORA X1 component is a read-only graphics-capability probe. It is not a GPU/display driver or DLSS-equivalent upscaler. Graphics vendor driver downloads should only be obtained from the linked manufacturer's official support page.
